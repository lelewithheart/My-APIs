# My-APIs

A catalog of niche API products with practical commercial use cases.

## API catalog

Each folder under `/apis` contains an OpenAPI 3.0 spec for one productized API.

1. `carbon-budget-api` — Personal and small business carbon budget recommendations.
2. `dispute-letter-api` — Drafts structured consumer dispute letters from case facts.
3. `food-shelf-life-api` — Shelf life and spoilage risk estimates for common foods.
4. `local-grant-matcher-api` — Matches users to local grants and aid opportunities.
5. `micro-insurance-quote-api` — Event/device micro-insurance quote estimation.
6. `pet-travel-rules-api` — Travel requirement checks for pets by route.
7. `rental-deposit-risk-api` — Deposit dispute risk scoring for rental cases.
8. `shift-swap-fairness-api` — Fairness scoring and suggestions for shift swaps.
9. `subscription-pricing-watch-api` — Monitors and compares SaaS subscription prices.
10. `utility-outage-risk-api` — Outage probability and preparation recommendations.
11. `warranty-eligibility-api` — Warranty coverage checks from purchase/failure data.
12. `water-usage-benchmark-api` — Water use benchmarking by household profile.

## Notes

- These are API product blueprints/specifications.
- You can implement each spec as an independent service and monetize them separately.
